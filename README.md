# 안양천 테니스장 예약

양천구 통합예약포털에서 3번 코트의 지정 날짜와 시간을 확인하고 신청하는 작업 폴더입니다.

현재 계획: **2026년 12월 일요일 6·13·20·27일을 우선 신청한 뒤, 수요일 2·9·16·23·30일**, 모두 **3번 코트 10:00~12:00**를 신청합니다. 접수 시작은 **2026년 11월 25일 10:00 한국 시각**입니다. 실제 완료 여부는 로컬 `.state/results.json`과 사이트의 ‘나의예약’에서 확인합니다.

## 실행

Python 3.10 이상과 `requirements.txt`의 패키지가 필요합니다.

```sh
python3 -m pip install -r requirements.txt
python3 reserve.py --login YOUR_ID
python3 reserve.py --dong YOUR_NEIGHBORHOOD
python3 reserve.py --dong YOUR_NEIGHBORHOOD --execute --wait
```

기본 실행은 신청서와 예약 가능 상태만 확인합니다. `--execute`를 지정해야 제출합니다. 비밀번호는 로그인 시 숨겨진 프롬프트에서 입력하며 파일에 저장하지 않습니다. 예약 신청에 필요한 개인정보 처리 동의만 선택하고, 선택 사항인 구정정보 문자 수신은 신청하지 않습니다.

실행기는 접수 시작 시각과 달력의 `OPEN` 상태를 모두 확인하고, 날짜별로 최신 신청서를 받아 순서대로 제출합니다. 제출 전에 기록을 남기며, 응답이 불확실하면 같은 신청을 자동 재전송하지 않습니다. 성공은 ‘나의예약’에 해당 코트·날짜·시간의 `예약완료`가 나타나는 경우에만 기록합니다. 동시 실행은 파일 잠금으로 방지합니다.

대기 중에는 4분 간격으로 로그인 상태를 확인합니다. 컴퓨터와 프로세스가 계속 실행 중이어야 합니다. 세션 만료, 사이트 변경, 매진, 네트워크 오류가 발생하면 완료되지 않을 수 있습니다.

## 비공개 로컬 데이터

